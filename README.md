# Market Intelligence Scraper - Sector Agropecuario

## 📊 Propósito
Este repositorio contiene herramientas desarrolladas en Python para la extracción automática (Web Scraping) y el procesamiento de datos de precios de mercados agrícolas. Está diseñado para apoyar la toma de decisiones estratégicas en la comercialización de productos como el aguacate Hass.

## 🎯 Objetivos
- **Monitoreo en tiempo real:** Captura de precios mayoristas de fuentes oficiales como el SIPSA (DANE).
- **Análisis de Oportunidades:** Comparación de precios locales vs. precios de exportación.
- **Automatización:** Reducir el tiempo de recolección de datos de mercados internacionales (Bolsa de Nueva York, Chicago, etc.).

## 🛠️ Tecnologías
- **Python:** Lenguaje principal.
- **BeautifulSoup / Selenium:** Para la extracción de datos de páginas web.
- **Pandas:** Para la estructuración y limpieza de las series de precios.
- **GitHub Actions:** (Planificado) Para ejecutar el scraper automáticamente cada semana.

## 📈 Insights Generados
El análisis de estos datos permite identificar ventanas de comercialización óptimas y mejorar el poder de negociación frente a compradores y exportadores.
